# משמרות — iOS

אפליקציית React Native ב־JavaScript, עם Expo SDK 57 ו־Expo Router. האפיון נמצא ב־`docs/product-spec.md` והרפרנס העיצובי ב־`design/shifts-prototype.html`. הממשק נבנה מרכיבי native, ללא WebView וללא המרת ה־HTML.

## הפעלה על iPhone

נדרשת בניית development: הווידג׳טים משתמשים בתוסף iOS שאינו כלול ב־Expo Go. בפרויקט מוגדר iPhone בלבד.

לבדיקת המסכים ב־Expo Go אפשר להריץ `npx.cmd expo start --go --clear`. כשמודול הווידג׳טים אינו מותקן, הסנכרון שלו מדולג והמסך מציג תצוגה מקדימה בלבד. גם development build ישן שנבנה לפני הוספת `expo-widgets` דורש בנייה והתקנה מחדש כדי להפעיל ווידג׳טים; רענון JavaScript אינו מוסיף מודולים native.

```powershell
npm.cmd ci
npx.cmd eas-cli@latest login
npx.cmd eas-cli@latest build --platform ios --profile development
npm.cmd start
```

בבניית EAS הראשונה יש לחבר את הפרויקט לחשבון Expo ולספק הרשאות חתימה של Apple. מזהה היישום המוגדר כרגע הוא `com.duduapp.shifts`; אפשר לשנות אותו לפני הבנייה הראשונה. מתקינים את הבנייה על המכשיר ופותחים בה את שרת הפיתוח. לבניית iOS Simulator במחשב Mac קיים הפרופיל `simulator`.

לא בוצעה בניית ענן, חתימה או העלאה לחנות במסגרת המימוש. קובץ `eas.json` מוכן לפרופילי development, simulator, preview ו־production. הוראות רשמיות: [EAS Build](https://docs.expo.dev/build/introduction/), [Expo Widgets](https://docs.expo.dev/versions/v57.0.0/sdk/widgets/).

## מה ממומש

- התחלה עם בחירת יום הבוקר הראשון בסבב; אין תאריכי דמו או חריגות דמו.
- היום, לוח חודשי, בדיקת תאריך, שיתוף והגדרות; מגירת פרטי יום עם עריכה.
- סבב 4/4/4/4 קדימה ואחורה, חריגות ליום בודד, שעות חוצות חצות, חופש והערות.
- שמירה מקומית, שימור הערות בעת איפוס חריגות, וטיפול בכשלי שמירה.
- גופני Assistant ו־Rubik מקומיים, צבעי הרפרנס, עברית ו־RTL, מצב בהיר/כהה/מערכת.
- לוח עברי וחגי ישראל באמצעות Hebcal, לרבות מועדים נדחים.
- תצוגה מקדימה לשיתוף, טווחים, העתקה ושיתוף native ללא הערות אישיות.
- התראות מקומיות עם בקשת הרשאה רק בעת הפעלה. תזמון מחדש בהתאם לשינויים.
- ווידג׳ט native בשלושה גדלים עם timeline, המוזן מאותו מנגנון חישוב.

## מבנה

| תיקייה           | תפקיד                                         |
| ---------------- | --------------------------------------------- |
| `src/app`        | מסכים וניווט Expo Router בלבד                 |
| `src/components` | רכיבי ממשק משותפים                            |
| `src/lib`        | תאריכים, סבב, טקסט שיתוף, תכנון התראות וחגים  |
| `src/state`      | מצב משותף, תצוגה ושמירה                       |
| `src/services`   | אחסון, התראות, רענון ברקע וסנכרון ווידג׳טים   |
| `src/widgets`    | תצוגת SwiftUI של הווידג׳ט, כתובה ב־JavaScript |
| `tests`          | בדיקות לוגיקה עסקית עם Node test runner       |

## בדיקות

```powershell
npm.cmd test
npm.cmd run lint
npm.cmd run typecheck
npx.cmd expo export --platform ios
```

בדיקת הטיפוסים מבוצעת גם על JavaScript באמצעות `checkJs`; אין צורך להמיר את הפרויקט ל־TypeScript. בדיקת export מאמתת יצירת bundle ו־Hermes bytecode, ואינה מחליפה קומפילציית Xcode או בדיקות במכשיר.

לפני הפצה יש להשלים על iPhone: מראה ו־RTL בכל המסכים, בחירת תאריך ושעה, מקלדת במגירה, VoiceOver וגופן מוגדל, שמירה לאחר סגירה, שיתוף, הרשאות התראה/סירוב, שינוי תזכורת אחרי עריכה, ושלושת גדלי הווידג׳ט במצב בהיר וכהה. בדיקות מכשיר אלה לא בוצעו בסביבת Windows.

## התראות ורענון

מתוזמנות עד 60 התראות עתידיות, עם מילוי מחדש בפתיחת האפליקציה ובמשימת רקע. כך נשארים מתחת לתקרת ההתראות המקומיות של iOS. הווידג׳ט מקבל 40 ימי עדכונים מראש, בחצות ובתחילת משמרת. לאחר תום הטווח הוא מבקש לפתוח את האפליקציה במקום להציג מידע ישן. אין הערות אישיות בווידג׳טים.

iOS קובע מתי משימת הרקע תרוץ; סגירה כפויה או ביטול רענון ברקע עלולים למנוע אותה. לכן מומלץ לפתוח את האפליקציה לפחות פעם בחודש. תזכורות משתמשות באזור הזמן המקומי של המכשיר; חישוב הפרשי ימי הסבב אינו תלוי במעבר שעון קיץ. [התנהגות BackgroundTask ב־iOS](https://docs.expo.dev/versions/v57.0.0/sdk/background-task/).

המידע נשמר מקומית בלבד; הסרת האפליקציה מסירה את הנתונים שלה. אין שרת, חשבון או סנכרון בין מכשירים בגרסה זו.
